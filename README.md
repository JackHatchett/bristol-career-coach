# Sample Skills for Bristol Tickets

Skills you can add to [Bristol Tickets](https://github.com/JackHatchett/bristol-tickets),
one folder each. They are the skills Bristol's job-search agent, career_coach,
works with.

## Add one

1. Open a skill's folder above, for example `jd-evaluation`.
2. Copy the address from your browser's address bar.
3. In Bristol Tickets, open Skills, press New Skill, choose Import From GitHub,
   paste the address and press Import.

The skill appears in the list and any agent can use it.

## The skills

| Folder | What it does |
| --- | --- |
| `jd-evaluation` | Judges whether a job is worth applying to |
| `cover-letter` | Writes a cover letter for one job |
| `resume-tailoring` | Tailors the resume to one job |
| `base-resume-update` | Updates the master resume |
| `interview-prep` | Prepares for an upcoming interview |
| `session-closure` | Opens and closes a job-hunting session |
| `searching-job-boards` | Finds a company's open job postings |
| `voice-lint` | Checks a draft written in your voice |
| `harvesting-job-alerts` | Turns job-alert email into a feed of postings |
